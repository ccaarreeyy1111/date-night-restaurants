# Cleveland Date Night Restaurants

A personal date-night guide to 59 of Cleveland's nicest restaurants, speakeasies, and cocktail bars — with photos, signature dishes, "Finding it" entry guides for the speakeasies, and a Been there / Want to go tracker that saves in your browser.

**Live site (GitHub Pages):** https://ccaarreeyy1111.github.io/date-night-restaurants/

On iPhone: open the live site in Safari, tap Share, then "Add to Home Screen" — it installs as a full-screen web app named "Date Night" with its own icon.

The whole site is a single self-contained `index.html` (all photos embedded), so there are no other files to deploy. Built with Muse.
